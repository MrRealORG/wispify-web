01Install

Which file do I download?

From the latest release: Wispify-x.y.z-setup-x64.exe is the installer (per-user, no admin rights), wispify-portable.exe runs without installing.

What do I need?

Windows 10 or 11, 64-bit, with WebView2 (built into Windows). Any x86-64 CPU with SSE4.2 works; AVX is not required. Voice needs a microphone and a one-time model download of about 57 MB.

Is it free?

Yes. Wispify is free and MIT licensed.

Mac or Linux?

Not at the moment. Wispify is built and tested for Windows 10 and 11.

02Voice

How do I start?

Press Voice once in the app; the model downloads with a progress bar. Then hold F8, say “play” and a song, and let go. The Voice page has the full list of commands and a playground.

Push-to-talk, wake word or off?

Push-to-talk (default): the mic opens only while F8 is held, or until you stop talking after a quick tap. Wake word: say “Hey Wisp, next”; only commands that start with the wake word run, so game voice chat can't skip your songs. Off: no listening. Settings → Voice.

Does it work while I'm in a game?

Yes. The voice agent runs natively in the background and the webview isn't involved until a command is understood. The confirmation toast is click-through and never takes focus. For exclusive-fullscreen games, where no window can be drawn on top, turn on the confirmation chime.

Which voice model should I use?

Whisper base.en is the default and the best balance. Tiny is faster and is what Low-impact mode picks; Small is more accurate if your CPU is fast. Switch in Settings → AI Voice.

It misheard me.

Push-to-talk forgives a lot: sound-alikes (“necks” → next), one-letter slips (“puase”) and bare song names. If it keeps missing, raise mic sensitivity in Settings → Voice, or speak the title and artist together: “play Starboy by The Weeknd”.

04Stage

How do I open it?

Ctrl Alt V, or ⋯ More → Stage. Pick Fullscreen or Wallpaper in the sheet, then a template. Esc closes fullscreen.

What does Wallpaper mode do?

It places the Stage behind your desktop icons as a live wallpaper and restores your normal wallpaper when it closes. If Windows doesn't offer that desktop layer, it falls back to fullscreen. Lock makes it click-through.

Why are there no lyrics for some songs?

Lyrics come from LRCLIB (word-timed when available), with YouTube captions and YouTube Music lyrics as fallbacks. When none of them has the song, the Stage hides the lyrics instead of showing something wrong.

Will it slow my PC down?

The Stage window only exists while it's open, loads just the active template's visualizer, draws once per frame and caps at 60 fps (30 on Low-impact, with no glow or spin). It stops drawing when the music is paused or the Stage is covered.

05Player & sound

Where does the music come from?

One search covers Audius, JioSaavn, YouTube Music, Deezer, iTunes, Internet Archive and radio stations. You can download songs to listen offline and save them to your music folder.

Where did the buttons go?

The main screen is kept calm on purpose. Library, Discover, Download, Save to folder, Copy link, Show video, Stop, Shuffle/Repeat, Sleep timer, Player style and Settings are all in the ⋯ More menu. The Sound studio opens from the dock.

What is Low-impact mode?

A switch in Settings for older PCs: less CPU and battery. It picks the Tiny voice model, halves the Stage frame rate and turns off glow and spin.

Does closing the window quit?

No. Close hides Wispify to the tray, so music and voice keep running. Quit from the tray icon.

06Troubleshooting

Voice says it can't use the microphone.

The voice screen tells you whether it's a permission problem or a missing mic. For permission, open Windows Settings → Privacy & security → Microphone and allow desktop apps. Then press Try again, or Type instead.

The app closes the first time I speak.

That was a bug in versions before 2.0 on CPUs without AVX. Since 2.0 Wispify is built for a portable SSE4.2 baseline and runs whisper behind a crash guard. Update to the latest release.

A YouTube song won't play.

Since 2.1.3, songs that resolve but won't play fall back to YouTube's official player automatically instead of being skipped.

Wallpaper mode shows a fullscreen Stage instead.

That's the fallback when Windows doesn't expose the desktop layer. Fullscreen works the same way; close it with Esc.

07Privacy

Speech is transcribed on your PC by whisper.cpp. In push-to-talk the mic is open only while you hold the key. In wake-word mode a lightweight local voice gate listens for speech and only runs Whisper when it hears some. Searches, streams and lyrics are fetched from the music and lyrics services listed above, as any player would.

This website has no analytics or cookies. The voice playground runs in your browser; the optional Mic button uses your browser's own speech service.

08Build from source

You need Node.js 20+, Rust stable and the Tauri 2 prerequisites (on Windows: MSVC build tools, WebView2, CMake, LLVM/Clang).

git clone https://github.com/MrRealORG/Wispify.git
cd Wispify
npm ci
npm run tauri dev     # run the app
npx tauri build       # release build → src-tauri/target/release/

Tests: npm run build && npm test for the UI, cargo test --manifest-path src-tauri/Cargo.toml --lib for Rust. Keep the portable SSE4.2 target in src-tauri/.cargo/config.toml: a native build crashes on older CPUs.
