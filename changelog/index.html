2.1.1

2026-11-16

Changed

  • One seek bar, a transport-only compact view, a lyrics strip under the player and grouped Settings. The title label is off by default.
  • Voice: anti-aliased resampling, adaptive trim and gain normalisation, beam search, and a forgiving push-to-talk grammar: sound-alikes, one-edit near misses and bare song names. New speed, nightcore and bass commands and clearer toasts.
  • Effects (reverb, bass, the spectrum) work on YouTube and other non-CORS streams through a local range proxy. Real nightcore, speed and slowed; reverb costs no CPU when off.
  • Lyrics: smarter title and artist cleanup with duration matching, LRCLIB search fallbacks, then YouTube captions and YouTube Music lyrics.
  • Stage: adaptive 30/60 fps, pauses when covered, lean FFT messaging between windows.
  • The widget stops painting while hidden or minimized.

2.1.0

2026-11-16

Added

  • New app icon — a royal-blue squircle with three rounded bars and a wisp curl. Used for the exe, installer, tray, favicon and the in-app logo.
  • Stage — a fullscreen / live-wallpaper visualizer (⋯ → Stage, or Ctrl+Alt+V). Album art as a slowly turning disc with audio-reactive bars and a soft glow, big karaoke-style synced lyrics (LRCLIB, word-timed when available, cached; hidden gracefully when a song has none), clock + date, and the queue on a curved "orbit" slider with Refresh · Dim · Lock · Close buttons. Background: blurred album art, solid, or your own picture (no bundled wallpapers).
  • Two modes: Fullscreen (Esc closes) and Wallpaper — on Windows the Stage sits behind the desktop icons (WorkerW), detaches and repaints the wallpaper on close; falls back to fullscreen when the desktop layer isn't available. Lock makes it click-through.
  • 8 templates: Orbit, Minimal, Vinyl, Wave, Ring, Neon, Cinematic, Particles. Each one is customizable (colour, visualizer, bar style / count / height, glow, lyrics on/off + size + position, song title, clock, disc art/vinyl/off + spin, queue slider, background + blur + dim) and saved per template; Reset restores the preset.
  • Real audio reactivity: the main window's WebAudio analyser streams 64 FFT bins to the Stage (~30 fps, 15 on Low-impact). Sources WebAudio can't tap (YouTube embed, CORS-locked streams) get a gentle synthetic pulse.
  • Light by design: separate window created on open and destroyed on close, only the active template's visualizer is loaded, one canvas-2D draw per frame (no shadowBlur, no CSS filters), capped at 60 fps (30 on Low-impact, no glow / spin), and the loop stops when paused or hidden.
  • Orbit queue: Up next opens as a curved slider — scroll, drag or arrow keys turn it with a spring, the focused song grows, click / Enter plays. The list view (remove / clear) is one tap away.
  • Settings → Stage (mode + "Open Stage…"); "Stage on/off" is a rebindable global shortcut.
  • Hardware media keys and the OS media flyout (Media Session).

Changed

  • Calmer main screen: art → title → one play row → a small dock (Up next · Like · Volume · Sound studio). Header is just Voice and ⋯ More. Nothing was removed: Library, Discover, Download, Save to folder, Copy link, Show video, Stop, Shuffle/Repeat, Sleep timer, Player style and Settings all live in the ⋯ menu; Sound studio opens as a sheet.
  • Voice screen: a live mic orb that follows your level, a 10-second countdown line, clear phases (Getting the mic ready → Listening → Understanding) and errors that stay on screen with Try again / Type instead (permission vs. missing-mic messages). The voice hotkey on an error retries.
  • Spring easing everywhere sheets open; every new animation is transform/opacity only and stops with Animations off / Low-impact.

Fixed

  • Shuffle never ended (and could replay songs); a shuffle pass now plays each song once and stops unless Repeat is on.
  • Previous with shuffle on jumped to the neighbouring row instead of the song you actually heard before.
  • "Play next" was ignored while shuffle was on.
  • Repeat-one rebuilt the audio element and re-fetched the stream each loop (gap + extra network); it now loops in place.
  • Queue edits left shuffle/history positions pointing at the wrong songs.
  • Esc in a search field with text collapsed the widget (stale key handler) instead of clearing the field.
  • Mouse wheel over the volume slider did nothing.
  • Every panel change fired a second native window resize (visible jank).
  • Changing the collapsed style resized from inside a React state updater (ran twice in StrictMode).
  • Hold-to-talk release could be missed while the voice phase changed.
  • Tray "Show Wispify" / tray click didn't restore a minimized widget.

2.0.1

2026-11-01

Fixed

  • No more native Windows title bar / see-through window. The old accent-policy acrylic/blur plus a SetWindowRgn rounded clip made Windows draw the classic caption (title, — ☐ ✕) over Wispify's own title bar and left a washed, translucent "Aero Basic" panel. The window is now frameless for real (caption/sysmenu/sizing styles are stripped after every style rebuild), opaque Midnight Glass (#0b0b12) by default, with DWM rounded corners + native shadow on Windows 11. "Glass" now means real Windows 11 Mica only and stays near-opaque; Windows 10 stays solid.

Changed

  • Faster: startup JS 553 → 370 KB (framer-motion removed), Settings / Library / Onboarding load lazily (prefetched on idle), 5-minute search cache, preconnect to search hosts, no backdrop blur anywhere.
  • Ultra-minimal main screen: player-layout chips moved to Settings, one quiet meta line, "FULL" badges dropped (only previews are tagged), no eyebrow/filler copy, monochrome surfaces with one accent.
  • New UI sounds: original synthesized macOS-style pops / glass tinks / felt clicks, all < 150 ms and ≤ -20 dBFS; default effects volume 50.
  • Default voice model: Whisper base.en q5_1 (see docs/VOICE_MODEL_BENCH.md). Pressing Voice the first time downloads it with progress; Tiny / Small remain selectable.

2.0.0

2026-11-01

The "play it while you game" release: a background voice agent, a new look, and the crash + CPU fixes low-spec PCs needed.

Added

  • Background voice control (Rust voice agent). Works while a game is fullscreen and Wispify is in the background — the webview is never involved until a command is understood.
  • Push-to-talk (default, F8): the mic opens only while the key is held (or until you stop talking after a quick tap) and closes right after — zero CPU when idle.
  • Wake word ("Hey Wisp, next"): an always-on, near-zero-CPU energy VAD gate; whisper only runs on speech, and only commands that start with the wake word execute, so game voice chat can't skip your songs.
  • Commands: play <song/artist>, next, previous/back, pause/hold/stop, resume, save, volume up/down, volume 40, mute, slowed on/off, reverb on/off, repeat [one/all/off], shuffle [on/off], what's playing.
  • Grammar lives in Rust (src-tauri/src/commands.rs) with unit tests.
  • Overlay toast ("Playing Blinding Lights", "Next", "Saved"): a tiny click-through, topmost window shown with SW_SHOWNOACTIVATE — it never steals focus from your game. Optional confirmation chime for exclusive fullscreen games where no window can be drawn.
  • New global hotkeys: push-to-talk, volume up/down, slowed, reverb, shuffle, repeat, show/hide — plus game-friendly defaults for next/previous/save.
  • Settings → Voice control: mode, wake word, mic sensitivity, toast and chime switches, and a "What can I say?" cheat sheet.
  • Issue templates, PR template, this changelog.

Changed

  • New "Midnight Glass" design: Windows 11 caption buttons (minimize, mini-player, close-to-tray with the red hover), Segoe UI Variable typography, one cohesive control set (segmented tabs, switches, sliders, fields, thin overlay scrollbars), a calm violet default accent.
  • Close now hides to the tray (music and voice keep running); quit from the tray.
  • Windows build workflow: portable SIMD build, unit tests before bundling, versioned installer name, GitHub Release on v* tags.

Fixed

  • Crash when speaking. whisper.cpp was compiled with GGML_NATIVE=ON, so the CI runner's AVX2/AVX-512 instructions were baked into the exe; on CPUs without them the app died with an illegal-instruction fault the first time whisper ran. Builds now target a portable SSE4.2 baseline (src-tauri/.cargo/config.toml + workflow env).
  • Release builds used panic = "abort", so any panic on a background thread killed the whole app. Now unwind, and whisper + the voice worker run behind catch_unwind.
  • Microphones that deliver 32-bit integer / unsigned 16-bit samples are supported instead of failing.
  • VAD buffer underflow when a speech segment ended mid-chunk (found by the new tests).
  • Search results were rendered below the home hero and the volume row (looked like search did nothing); they now appear right under the search box.
  • Scrolling over the expanded panel or Settings changed the volume.
  • Header buttons overflowed and pushed the window controls off-screen while a song was playing.

Performance

  • whisper encodes only the length of the spoken command (audio_ctx) instead of a 30-second window, single pass, no temperature fallback — a fraction of the old CPU time per command.
  • WebAudio graph and UI-sound contexts are suspended while nothing plays (an open AudioContext renders silence on the audio thread forever).
  • Playback clock re-renders at 1 Hz while the widget is unfocused.
  • Looping CSS animations pause whenever the widget is not the focused window.
  • The YouTube embed handshake stops polling once the player answers.
  • Overlays no longer use backdrop blur inside the native window.
